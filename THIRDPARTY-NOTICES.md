# Third-party dependencies

Browser dependencies are supplied locally for offline review. Marked is used by the build and installed from npm.

| Dependency       | Version / source                       | Licence                               |
| ---------------- | -------------------------------------- | ------------------------------------- |
| D3               | 7.9.0                                  | ISC                                   |
| TopoJSON Client  | 3.1.0                                  | ISC                                   |
| World Atlas      | 2.0.2, Natural Earth-derived geography | ISC; Natural Earth public-domain data |
| Chart.js         | 4.4.1                                  | MIT                                   |
| Marked           | 18.0.14                                | MIT                                   |
| MathJax          | 3.2.2                                  | Apache 2.0                            |
| Inter            | Google Fonts distribution              | SIL Open Font License 1.1             |
| Playfair Display | Google Fonts distribution              | SIL Open Font License 1.1             |

Licence texts are included in `assets/vendor/licenses/`. Font files remain unmodified. SVG logo lettering is outlined from Playfair Display. Original research and photographic assets are retained from the source portfolio and are not represented as third-party stock imagery.

Carbon airport data: OurAirports public-domain snapshot, accessed 28 September 2026 (https://ourairports.com/data/). Additional fuel and allocation data: ICAO Carbon Emissions Calculator Methodology v13.1, August 2024; source URL and version are retained in data/json/icao-v13-curves.json. Operator catalogue entries link their sources individually.
