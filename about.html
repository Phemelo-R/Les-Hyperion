Focus areas

This site presents reproducible analyses in GIS, Quantitative Ecology, and Biostatistics — examples are available in both R and Python.

Want to try live code? Visit the Interactive Runner to experiment in-browser with R and Python.

What you'll find here

  • Reproducible analyses using R and Python (notebooks & scripts).
  • GIS workflows, spatial analyses, species distribution & abundance models.
  • Quantitative ecology: population models, diversity metrics, mixed models.
  • Biostatistics: experimental design, survival analysis, GLMs, diagnostics.

Interactive & portable

Try short code snippets directly in your browser — no server setup required. All interactive execution uses in-browser runtimes (Pyodide for Python, WebR for R).

Quick start

  1. Click Run code → Interactive.
  2. Choose R or Python from the language switcher.
  3. Edit the example and click Run. Output and plots appear below the editor.

If you'd like, I can help port a set of your notebooks into the interactive examples or wire a Binder/JupyterHub link.
