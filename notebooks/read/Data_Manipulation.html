Data Manipulation in R

Tidyverse Tools for Ecological Data Wrangling

"Happy families are all alike; every unhappy family is unhappy in its own way." — Leo Tolstoy, Anna Karenina (1878)

"Tidy datasets are all alike, but every messy dataset is messy in its own way." — Hadley Wickham (2014)

Introduction

In Part 1, we laid the foundations of R — objects, data types, structures, and packages — working entirely in base R. In this section, we move to the Tidyverse: a curated collection of R packages that share a common design philosophy, grammar, and data structure, making data manipulation more intuitive, readable, and reproducible.

Throughout this page, we will work exclusively with the Palmer Penguins dataset (palmerpenguins; Horst, Hill & Gorman, 2020) — a real ecological dataset from the Palmer Long-Term Ecological Research (LTER) site in Antarctica.

References:

  • Wickham, H. (2014). Tidy data. Journal of Statistical Software, 59(10), 1–23. https://doi.org/10.18637/jss.v059.i10
  • Horst, A.M., Hill, A.P. & Gorman, K.B. (2020). palmerpenguins. https://doi.org/10.5281/zenodo.3960218
  • Wickham, H. et al. (2019). Welcome to the tidyverse. Journal of Open Source Software, 4(43), 1686. https://doi.org/10.21105/joss.01686

The Tidyverse

The Tidyverse is an opinionated collection of R packages created by Hadley Wickham (now at Posit, formerly RStudio) and maintained by a growing team of contributors. Installing tidyverse installs eight core packages at once:

Package Primary function
readr Fast and consistent data import/export
dplyr Data manipulation (filter, select, mutate, summarise)
tidyr Data reshaping (pivoting, nesting, separating)
stringr String (text) manipulation
forcats Factor manipulation
lubridate Date and time manipulation
purrr Functional programming (iteration without loops)
ggplot2 Data visualisation (covered in Notebook 3)

All tidyverse functions share:

  1. Consistent syntax: the first argument is always the data.
  2. Tidy data expectations: rows are observations, columns are variables.
  3. Pipe compatibility: designed to be chained with the pipe operator.

Reference: https://tidyverse.org

Tidy Data

Tidy data is a standardised way of organising tabular data that makes downstream analysis straightforward (Wickham, 2014). A dataset is tidy when:

  1. Every column is a variable — a single attribute of the observations.
  2. Every row is an observation — a single record.
  3. Every cell contains a single value — no multiple values crammed into one cell.

The penguins dataset is already tidy — we can verify this immediately:

The Pipe Operator

The pipe operator passes the output of one function directly as the first argument of the next, enabling a readable, left-to-right chain of operations. Two pipes are in common use:

Pipe Source Shortcut
%>% magrittr package (loaded with tidyverse) Ctrl+Shift+M / Cmd+Shift+M
|> Native R (≥ 4.1) Same shortcut (configurable)

Read the pipe as "and then":

R · Cell 5 · In [5] 
# Without a pipe: nested, inside-out, hard to read
result_nested <- summary(na.omit(subset(penguins, species == "Adelie")))

# With the pipe: sequential, left-to-right, readable
result_piped <- penguins |>
  subset(species == "Adelie") |>
  na.omit() |>
  summary()

# Both produce identical output
all.equal(result_nested, result_piped)
Output

readr — Reading and Writing Data

readr provides fast, consistent functions for importing and exporting rectangular data. It is the tidyverse replacement for base R's read.csv().

Key advantages over base R

  • Automatically guesses column types (but allows manual override)
  • Never converts strings to factors by default (unlike read.csv)
  • Produces a tibble (a modern data frame) rather than a base data frame
  • Clearly reports any parsing problems

dplyr — Data Manipulation

dplyr is the core data manipulation package of the tidyverse. It provides six primary verbs that cover the vast majority of data manipulation needs (Wickham et al., 2023):

Verb Action
filter() Subset rows by a logical condition
select() Subset columns by name or position
mutate() Add or modify columns
summarise() Collapse rows to summary statistics
arrange() Sort rows
rename() Rename columns

These verbs are almost always combined with group_by(), which applies any operation separately within groups.

Reference: Wickham, H., François, R., Henry, L., Müller, K. & Vaughan, D. (2023). dplyr: A Grammar of Data Manipulation. https://dplyr.tidyverse.org

1. filter() — Row subsetting

filter() retains rows that satisfy one or more logical conditions. The double-equals == tests equality; a single = inside filter would cause an error.

Operator Meaning
== Equal to
!= Not equal to
>, < Greater/less than
>=, <= Greater/less than or equal to
& AND (both conditions must be true)
| OR (at least one condition must be true)
%in% Value is in a vector
! NOT (negation)
is.na() Is missing

Putting It All Together — A Complete Workflow

Here we demonstrate a complete data manipulation pipeline: from raw data to a clean, summarised, analysis-ready table.

R · Cell 57 · In [57] 
# Complete workflow: raw penguins data → clean summary for analysis
penguin_summary <- penguins_raw |>

  # 1. Clean column names with janitor (or rename manually)
  rename(
    species       = Species,
    island        = Island,
    bill_length_mm = `Culmen Length (mm)`,
    bill_depth_mm  = `Culmen Depth (mm)`,
    flipper_length_mm = `Flipper Length (mm)`,
    body_mass_g    = `Body Mass (g)`,
    sex            = Sex,
    year           = `Date Egg`
  ) |>

  # 2. Extract clean species name
  mutate(
    species = str_remove(species, " Penguin.*") |> str_trim(),
    species = as.factor(species)
  ) |>

  # 3. Remove rows with missing morphological measurements
  drop_na(bill_length_mm, bill_depth_mm, flipper_length_mm, body_mass_g) |>

  # 4. Add derived variables
  mutate(
    body_mass_kg  = body_mass_g / 1000,
    bill_ratio    = bill_length_mm / bill_depth_mm,
    size_class    = case_when(
      body_mass_g < 3500  ~ "small",
      body_mass_g < 4500  ~ "medium",
      TRUE                ~ "large"
    )
  ) |>

  # 5. Summarise by species
  group_by(species, island) |>
  summarise(
    n              = n(),
    mean_mass_kg   = mean(body_mass_kg, na.rm = TRUE),
    sd_mass_kg     = sd(body_mass_kg, na.rm = TRUE),
    mean_bill_ratio = mean(bill_ratio, na.rm = TRUE),
    .groups = "drop"
  ) |>

  # 6. Sort by mean mass descending
  arrange(desc(mean_mass_kg))
